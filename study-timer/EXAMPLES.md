# 📖 Примеры использования Study Timer

## Быстрый старт

### 1️⃣ Запустить приложение
```bash
./study-timer  # или study-timer.exe на Windows
```

Вы увидите главное меню с опциями.

### 2️⃣ Начать отслеживание времени

Выберите опцию **1** и введите название предмета:
```
Выберите пункт: 1
Введите название предмета: Математика
```

Таймер запустится и будет отсчитывать время.

### 3️⃣ Управление таймером

Во время работы таймера:
- **Enter** - пауза/возобновление
- **q** - остановить и сохранить сессию
- **Q** - то же самое

Например:
```
▶ ТАЙМЕР РАБОТАЕТ
Предмет: Математика
Время:   00:15:32

Нажмите Enter для паузы или введите 'q' для выхода: q
✓ Сессия сохранена!
```

### 4️⃣ Просмотр статистики

После сохранения сессий можно просмотреть статистику:

**Статистика на сегодня (опция 3):**
```
┌─────────────────────────────────┐
│ СТАТИСТИКА НА СЕГОДНЯ          │
├─────────────────────────────────┤
│ Математика: 1ч 30м             │
│ Физика: 45м                     │
│ Итого: 2ч 15м                   │
└─────────────────────────────────┘
```

**Статистика за неделю (опция 4):**
```
┌──────────────────────────────────┐
│ СТАТИСТИКА ЗА НЕДЕЛЮ            │
├──────────────────────────────────┤
│ 2026-05-28: 3ч 20м              │
│ 2026-05-29: 2ч 45м              │
│ 2026-05-30: 4ч 10m              │
│ Итого за неделю: 23ч 15м        │
└──────────────────────────────────┘
```

**Статистика по предметам (опция 5):**
```
┌──────────────────────────────────┐
│ СТАТИСТИКА ПО ПРЕДМЕТАМ         │
├──────────────────────────────────┤
│ Математика: 8ч 30m              │
│ Физика: 6ч 45m                  │
│ Химия: 5ч 20m                   │
│ История: 3ч 10m                 │
└──────────────────────────────────┘
```

## Типичный рабочий день

```
09:00 - Запуск, начало учебы "Математика" (2ч 30м)
11:30 - Перерыв, сохранение сессии

12:00 - Возобновление "Физика" (1ч 45м)
13:45 - Обед

14:15 - Начало "Программирование" (3ч 20м)
17:35 - Конец дня

20:00 - Проверка статистики через опцию 3
        (всего за день: 7ч 35м по трем предметам)
```

Приложение сохраняет данные в `study_stats.json`:

```json
[
  {
    "date": "2026-06-03",

    "subject": "Математика"
  },

  },
  {
    "date": "2026-06-02",
    "seconds": 7200,
    "subject": "История"
  }
]
```

## Советы

💡 **Совет 1:** Используйте точные названия предметов для лучшей статистики

💡 **Совет 2:** Регулярно проверяйте статистику мотивирует продолжать учиться

💡 **Совет 3:** Сохраняйте `study_stats.json` в облаке для резервной копии

💡 **Совет 4:** Перезагружайте приложение каждый день для чистого интерфейса
