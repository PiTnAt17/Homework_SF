# 🚀 Быстрый старт

## За 2 минуты до первого запуска

### 1. Компилируем

**Windows:**
```bash
cd study-timer
build.bat
.\build\study-timer.exe
```

**Linux/Mac:**
```bash
cd study-timer
make
./study-timer
```

### 2. Используем

```
Выберите пункт: 1
Введите название предмета: Математика
[таймер работает]
q → сохранить
```

### 3. Смотрим результат

```
Выберите пункт: 3  (статистика за сегодня)
[видим сохраненное время]
```

**Готово!** 🎉

---

## Команды

| Опция | Действие |
|-------|----------|
| 1 | Запустить таймер |
| 2 | Остановить таймер |
| 3 | Статистика на сегодня |
| 4 | Статистика за неделю |
| 5 | Статистика по предметам |
| 0 | Выход |

## Если что-то не работает

1. **Нет компилятора?**
   - Windows: Установить MinGW или Visual Studio
   - Linux: `sudo apt install g++`
   - Mac: `brew install gcc`

2. **CMake ошибка?**
   - Используйте `build.bat` (Windows) или `make` (Linux/Mac)

3. **Цвета не работают?**
   - Нормально на старых консолях, приложение работает без цветов

Подробнее: смотрите `SETUP.md`
