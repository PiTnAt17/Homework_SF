# Study Timer - Консольное приложение для подсчета учебного времени

Мини-приложение на C++ для подсчета, отслеживания и анализа времени, проводимого за учебой.

## 🎯 Функции

- ⏱️ **Запуск/Остановка таймера** с указанием предмета
- 💾 **Автосохранение статистики** в JSON формате
- 📊 **Анализ статистики**:
  - За сегодня
  - За последнюю неделю
  - По предметам (общее время)
- 🎨 **Красивый консольный интерфейс** с цветами и подсказками

## 📋 Требования

- CMake 3.10+
- C++17 компилятор (MSVC, GCC или Clang)
- Windows 10+ (для ANSI поддержки)

## 🔨 Сборка

```bash
cd study-timer
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

## ▶️ Запуск

```bash
./study-timer.exe  # Windows
./study-timer      # Linux/Mac
```

## 📝 Использование

1. **Запустить таймер** - выберите "1", введите название предмета
2. **Остановить таймер** - нажмите Enter для паузы, 'q' для выхода и сохранения
3. **Просмотреть статистику** - выберите нужный раздел (3, 4 или 5)

## 💾 Данные

Статистика сохраняется в файл `study_stats.json` рядом с приложением:

```json
[
  {
    "date": "2026-06-03",
    "seconds": 3600,
    "subject": "Математика"
  }
]
```

## 🎨 Интерфейс

- Цветные сообщения для быстрого восприятия
- Боксы и таблицы для организации информации
- ANSI поддержка для красивого вывода
